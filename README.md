# FRC Knowledge — Free Overview Edition

A static, mobile-friendly FRC and robotics knowledge site. It uses no paid API, backend, account, or subscription.

## Search experience
- Searches the built-in curated knowledge entries in the browser.
- Shows a concise overview and key points first.
- Provides an expandable detailed explanation.
- Lists original documentation and further-reading links.
- Provides targeted external search links for FIRST, WPILib, REV, CTRE, Chief Delphi, GitHub, and broader robotics.

## Important limitations
- The overview text is curated and stored in `app.js`; it is not generated by AI.
- External search links open search pages. The site does not automatically fetch, copy, or summarize live webpages. This avoids requiring a paid search API and avoids relying on sites that block automated access.
- Source pages can change. Check the original documentation, especially for current FRC rules, firmware, and software versions.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of a public GitHub repository.
2. In repository Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
3. Wait for the site URL to appear in Settings → Pages.

No API keys or environment variables are required.
