ABOUT THE PROJECT

FRC knowledge, in one place.

FRC Knowledge is a searchable hub for FIRST Robotics Competition information. The goal is to make reliable technical information easier to discover, understand, and share.

Early prototype
Search uses a curated local knowledge library with concise overviews, expandable explanations, and links to original references. External search links open public search results; this prototype does not automatically copy or summarize live webpages. Always check current FIRST and manufacturer documentation for authoritative information.
